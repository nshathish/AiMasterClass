# AI Master Class

Hands-on projects and exercises from the AI Master Class.

## Day 1: Building an AI support copilot

We learned how to build a .NET support copilot using the OpenAI Responses API, classify support tickets with structured JSON output, and connect the model to business tools. We explored conversation state and tool execution policies, then extended the exercise with Durable Functions workflows and a React admin interface for human approval of actions such as refunds and order cancellations.
